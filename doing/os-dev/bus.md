# バス
## 導入
OSはいろいろなものとデータをやり取りする

PCの中って、CPU、メモリ、グラボ、SSD、USBコントローラなど色々な部品が載ってある。これらの部品同士がデータをやり取りするには、共通の通り道が必要。

この通り道をバスと呼びます。道に走っているバスとおんなじ形です。実体はマザーボード上に走っている配線の束です。
## PCの中のやり取り
バスはマザボにくっついていて、CPU、メモリ、グラボ、SSD、USBコントローラなど色々な部品がバスを通ってデータをやり取りする。
* 例：キーボード（外部からの入力）
  * キーボード ⇒ マザーボードが持つメモリバッファ ⇒ バスを通って ⇒ CPU

## バス規格
* 昔
  * PCI：パラレル通信をする約束
* 今
  * PCIe：シリアル通信をする約束

PCIもPCIeも配線の束であることは変わらない。PCIでは配線の種類がパラレルだったが性能が頭打ちになった。そこでシリアルに送る配線にして本数は4本1組を、必要な数だけ並べる方式にした

:bulb:豆知識：移行期間の時にはPCI規格とPCIe規格どっちもついてたらしい。

### 「シリアル」と「パラレル」の違い
* パラレル（並列）
    - **複数本の線**で、同時に何ビットも送る
* シリアル（直列）
    - **少ない本数の線**で、1ビットずつ順番に送る

### なぜ新しくするときにパラレルからシリアルにしたのか？
一見、線が多いパラレルのほうが速そう。でもパラレルは「すべての線で同時に届く」のが前提で、速くするほどこのタイミング合わせが難しくなって頭打ちになった。
シリアルは1つずつデータを送るので揃える相手がいない。そのぶん1本を極端に速くできる。
足りなければ4本1組の配線を増やす設計。
