# バス
* PCI：マザボとつなぐためのバスの規格の一つ
### バス規格とは
PCの中って、CPU、メモリ、グラボ、SSD、USBコントローラなど色々な部品が載ってある。これらの部品同士がデータをやり取りするには、共通の通り道（＝バス）が必要

### PCIe
PCI（Peripheral Component Interconnect）は、PCの内部でCPUと周辺デバイス（グラフィックカード、ネットワークカード、サウンドカードなど）を接続するためのバス規格

自作PCの時につける細長いやつでしょ？最近はPCIeしかないけど昔のPCはPCI規格とPCIe規格どっちもついてたよね

### シリアルポートポートってなに？

そもそも、ポートとはコンピュータが外部とやりとりするための **“入出力の窓口”** のこと。

例：USBポート（USB機器と通信）、LANポート（ネットワーク）、HDMI（映像）、そして **シリアルポート**（文字やデータを順番に送る通信）

※ここで言う「ポート」は“物理的な口”の意味。ネットワークの「TCP 80番ポート」みたいな“番号”とは別物だよ。

### 「シリアル」と「パラレル」の違い

■パラレル（並列）

- **複数本の線**で、同時に何ビットも送る
- 昔のプリンタ端子とかで見たやつ

■シリアル（直列）

- **少ない本数の線**で、1ビットずつ順番に送る
- これが **シリアルポート**

今は高速化や配線の都合で、シリアル系が主流。
